# templates

Универсальный каркас-шаблон для 1С-Битрикс. Пустая, но полностью готовая
заготовка, на основе которой собираются сайты: лендинги, корпоративные
сайты, магазины.

## Что внутри

```
templates/
└── main/     каркас шаблона
```

В `main/` лежит:

- адаптивная вёрстка (десктоп / планшет / мобильный);
- тёмная тема и переключатели темы и размера шрифта в шапке;
- шаблоны компонентов: меню, хлебные крошки, форма связи, поиск;
- редактируемые области: логотип, название и описание компании;
- страницы-образцы: главная, внутренняя, каталог, контакты, 404.

Подробная документация и карта файлов — в [`main/README.md`](main/README.md).

## Установка

1. Скопировать папку `main` в `/local/templates/` сайта.
2. Применить шаблон в админке:
   Настройки → Настройки продукта → Сайты → Шаблоны сайтов.
3. Заменить логотип и заполнить включаемые области в `main/include/`.

## Требования

- PHP 7.4 и выше (проверено на 7.4 и 8.1)
- `short_open_tag = On` — шаблон использует короткие теги `<?`
