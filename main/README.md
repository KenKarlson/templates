# Шаблон main - Универсальный каркас для 1С-Битрикс

> Базовый шаблон для быстрой разработки сайтов на 1С-Битрикс. Подходит для лендингов, корпоративных сайтов и магазинов. Полностью адаптивен, поддерживает темную тему и печать.

## Что включено в каркас

- Полная адаптивность (десктоп, планшет, мобильный)
- Мобильное меню с анимацией, блокировкой скролла и свайпом
- Выпадающее подменю с поддержкой тач-устройств
- Темная тема (автоматическая через prefers-color-scheme)
- Стили для печати (скрывает навигацию, показывает URL ссылок)
- Доступность (ARIA-атрибуты, focus-visible, reduced-motion, высокий контраст)
- Ленивая загрузка изображений
- Плавная прокрутка к якорям
- Эффект шапки при скролле (скрытие/показ, тень)
- CSS-компоненты: кнопки, карточки, формы, таблицы, пагинация, алерты
- JavaScript-утилиты: debounce, throttle, toggleElement, getBitrixToken
- Страница 404 с поиском и популярными разделами
- 4 типа страниц: главная, внутренняя, каталог, контакты
- 3 расширения: лендинг, новости, магазин

## Настройка стилей

### Цветовая палитра

Все цвета определены в CSS-переменных в начале `assets/css/styles.css`:

```css
:root {
    --color-primary: #2563eb;       /* Основной цвет */
    --color-primary-hover: #1d4ed8; /* При наведении */
    --color-text: #1e293b;          /* Текст */
    --color-bg: #ffffff;            /* Фон */
    /* ... и другие */
}
```

**Как изменить:** отредактируйте значения в `assets/css/styles.css:14-62`.

### Шрифты

```css
:root {
    --font-family: -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, ...;
    --font-size-base: 16px;
    /* ... */
}
```

### Отступы

```css
:root {
    --spacing-xs: 4px;
    --spacing-sm: 8px;
    --spacing-md: 16px;
    --spacing-lg: 24px;
    --spacing-xl: 32px;
    /* ... */
}
```

## Сетка

Шаблон использует CSS Grid:

```html
<div class="grid grid-3">
    <div>Колонка 1</div>
    <div>Колонка 2</div>
    <div>Колонка 3</div>
</div>
```

Классы: `.grid-2`, `.grid-3`, `.grid-4`, `.grid-5`, `.grid-6`, `.grid-auto` - адаптивные (сужаются на мобильных).

## Адаптивность

Шаблон полностью адаптивен и поддерживает 3 брейкпоинта:

| Брейкпоинт | Ширина | Описание |
|------------|--------|----------|
| Десктоп | > 992px | Полная версия, горизонтальное меню |
| Планшет | 577px - 992px | 2 колонки, скрыты контакты в шапке |
| Мобильный | <= 576px | 1 колонка, бургер-меню, компактные отступы |

### Мобильное меню
- Открывается по клику на бургер
- Закрывается по клику на ссылку, вне меню, Escape, свайп вправо
- Блокирует скролл страницы при открытом меню

### Темная тема
- Автоматически включается через `prefers-color-scheme: dark`
- Можно переключать вручную через CSS-класс `dark` на `<html>`

### Печать
- Скрывает шапку, подвал, навигацию, кнопки
- Показывает URL ссылок
- Оптимизирует шрифты и отступы

### Доступность
- `prefers-reduced-motion` - отключает анимации
- `prefers-contrast: high` - увеличивает контраст
- Все интерактивные элементы имеют `focus-visible`
- ARIA-атрибуты для навигации и меню

## Подключение ресурсов

### CSS

```php
// В header.php уже подключен styles.css
$APPLICATION->SetAdditionalCSS($CSS_PATH . '/styles.css');

// Добавить свой CSS:
$APPLICATION->SetAdditionalCSS($CSS_PATH . '/custom.css');
```

### JavaScript

```php
// В header.php уже подключен main.js
$APPLICATION->AddHeadScript($JS_PATH . '/main.js');

// Добавить свой скрипт:
$APPLICATION->AddHeadScript($JS_PATH . '/utils.js');
```

## Для разработчиков

### Установка шаблона

**Важно:** папку `main` необходимо разместить в `/local/templates/`

```
/bitrix/
  /local/
    /templates/
      /main/           <-- этот шаблон
```

Не размещайте шаблон в `/bitrix/templates/` - это системная папка ядра Битрикс, которая может быть перезаписана при обновлении. Папка `/local/templates/` предназначена для пользовательских шаблонов и не затрагивается обновлениями.

### Начало работы

1. Скопируйте папку `main` в `/local/templates/`
2. Примените шаблон в настройках сайта (Администрирование -> Настройки -> Настройки продукта -> Сайты -> Шаблоны сайтов)
3. Замените `assets/img/logo.svg` на свой логотип
4. Настройте цвета в `assets/css/styles.css`
5. Наполните включаему
