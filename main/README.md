# Шаблон main - Универсальный каркас для 1С-Битрикс

> Базовый шаблон для быстрой разработки сайтов на 1С-Битрикс. Подходит для лендингов, корпоративных сайтов и магазинов. Полностью адаптивен, поддерживает темную тему и печать.

## Куда класть шаблон

Папку `main` нужно положить в `/local/templates/` — это папка для пользовательских шаблонов, она не затирается при обновлении ядра.

```
/ (корень сайта)
├── /bitrix/                    # ядро Битрикс (не трогаем)
├── /local/
│   └── /templates/
│       └── /main/              # <-- этот шаблон
├── /index.php                  # страницы сайта лежат тут
└── /about/index.php
```

Не кладите шаблон в `/bitrix/templates/` — это системная папка ядра, её может перезаписать обновление.

## Что включено в каркас

- Полная адаптивность (десктоп, планшет, мобильный)
- Мобильное меню с анимацией, блокировкой скролла и свайпом
- Выпадающее подменю с поддержкой тач-устройств
- Переключатель светлой/темной темы в шапке
- Переключатель размера шрифта А А А в шапке
- Темная тема (автоматическая и ручная)
- Стили для печати (скрывает навигацию, показывает URL ссылок)
- Доступность (ARIA-атрибуты, focus-visible, reduced-motion, высокий контраст, ссылка к контенту)
- Ленивая загрузка изображений
- Плавная прокрутка к якорям
- Эффект шапки при скролле (скрытие/показ, тень)
- CSS-компоненты: кнопки, карточки, формы, таблицы, пагинация, алерты
- Контейнер и защита от двойного контейнера, утилита `.full-width`
- JavaScript-утилиты: debounce, throttle, toggleElement, getBitrixToken
- Готовые шаблоны компонентов: меню, хлебные крошки, форма связи, поиск
- Страница 404 с поиском и популярными разделами
- 4 типа страниц-образцов: главная, внутренняя, каталог, контакты
- 3 расширения: лендинг, новости, магазин

## Важно про страницы

Файлы `index.php`, `page.php`, `catalog.php`, `contacts.php`, `404.php` лежат в шаблоне как **образцы**. Битрикс их оттуда не берёт. Физические страницы живут в корне сайта:

- `main/index.php` → копируется в `/index.php`
- `main/page.php` → копируется в `/about/index.php`, `/services/index.php` и т.д.
- `main/404.php` → копируется в `/404.php` и указывается в настройках сайта как страница 404

### Контейнер

Контейнер (`.container`) задаёт ширину и центрирует контент. Он уже открыт в шаблоне — в `header.php` сразу после `<main>`, а закрывается в `footer.php`.

Можно указать контейнер и в самой странице — **оба варианта работают**. Если окажется два контейнера, вложенный не даст двойных отступов: в CSS есть защита `.container .container`.

```
Вариант 1: контейнер только в шаблоне
  <main><div class="container"> ...контент страницы... </div></main>

Вариант 2: контейнер в странице (как в шаблонах мастера)
  <main><div class="container"> <div class="container"> ...контент... </div> </div></main>
```

Проще всего — оборачивать контент страницы в `<div class="container">` (Вариант 2), как это делает мастер установки. Тогда страница не зависит от версии `header.php`.

Секцию на всю ширину экрана оборачивайте в `.full-width`:

```html
<div class="full-width">Здесь во всю ширину</div>
```

### Шаблон страницы

Минимальная страница для корня сайта:

```php
<?
require($_SERVER["DOCUMENT_ROOT"] . "/bitrix/header.php");
$APPLICATION->SetTitle("Заголовок страницы");
$APPLICATION->SetPageProperty("description", "Описание для поисковиков");
?>

<div class="container">
	<h1><?$APPLICATION->ShowTitle(false)?></h1>

	<!-- Контент страницы -->
</div>

<?require($_SERVER["DOCUMENT_ROOT"] . "/bitrix/footer.php");?>
```

## Адаптивность

| Брейкпоинт | Ширина | Что происходит |
|------------|--------|----------------|
| Десктоп | > 992px | Полная версия, горизонтальное меню |
| Планшет | 577-992px | 2 колонки, скрыты контакты в шапке |
| Мобильный | <= 576px | 1 колонка, бургер-меню, компактные отступы |

### Мобильное меню
- Открывается по клику на бургер
- Закрывается по клику на ссылку, вне меню, Escape, свайп вправо
- Блокирует скролл страницы

### Темная тема
- Включается сама при `prefers-color-scheme: dark`
- Вручную: кнопка солнце/луна в правой части шапки
- Выбор запоминается в localStorage (`main-theme`)
- Класс `light` на `<html>` принудительно включает светлую тему

### Печать
- Скрывает шапку, подвал, навигацию, кнопки
- Показывает URL ссылок
- Оптимизирует шрифты и отступы

### Доступность
- Ссылка «Перейти к содержанию» в начале страницы
- `prefers-reduced-motion` — отключает анимации
- `prefers-contrast: high` — увеличивает контраст
- Все интерактивные элементы имеют `focus-visible`
- ARIA-атрибуты для навигации и меню

## Инструменты в шапке

В правой части шапки два элемента: переключатель размера шрифта (А А А) и кнопка темы (солнце/луна). Оба прячутся в `.header__tools` в `header.php`.

**Размер шрифта** — три кнопки `data-font-size="small|normal|large"`. Меняют множитель `--font-scale` через класс `font-size-*` на `<html>`. Выбор хранится в localStorage (`main-font-size`).

**Тема** — кнопка `data-theme-toggle`. Добавляет класс `dark` или `light` на `<html>`. Выбор хранится в localStorage (`main-theme`). Если пользователь не выбирал — работает системная тема.

### Как отключить

**Спрятать кнопки, но оставить код:**

```css
/* в assets/css/custom.css или styles.css */
.header__tools { display: none; }
```

**Убрать полностью:**
1. В `header.php` удалите блок `<!-- Инструменты: размер шрифта и переключение темы -->` целиком (весь `<div class="header__tools">...</div>`).
2. В `header.php` удалите инлайновый скрипт в `<head>` (комментарий «Применяем сохраненную тему...»).
3. В `assets/js/main.js` удалите вызовы `initThemeToggle();` и `initFontSize();` и сами функции (разделы 7 и 8).
4. В `assets/css/styles.css` можно удалить блоки `.header__tools`, `.font-size`, `.theme-toggle` и классы `html.font-size-*` — они больше не нужны. Не обязательно, просто чистота.

**Оставить только тему (без размера шрифта):**
Удалите из `header.php` только блок `<div class="font-size">...</div>` и вызов `initFontSize();` в JS.

**Оставить только размер шрифта (без темы):**
Удалите из `header.php` только `<button class="theme-toggle">...</button>` и вызов `initThemeToggle();` в JS.

## Шаблоны компонентов

Свои шаблоны компонентов лежат в `components/bitrix/<компонент>/<шаблон>/`. Они подхватываются автоматически при `IncludeComponent` с нужным именем шаблона.

| Компонент | Шаблон | Где используется |
|-----------|--------|------------------|
| `bitrix:menu` | `main` | Шапка сайта |
| `bitrix:menu` | `mobile` | Мобильное меню |
| `bitrix:menu` | `footer` | Подвал |
| `bitrix:breadcrumb` | `main` | Хлебные крошки |
| `bitrix:main.feedback` | `main` | Форма обратной связи |
| `bitrix:search.form` | `main` | Поиск |

### Важно: шаблон хлебных крошек возвращает строку

`bitrix:breadcrumb` выводится через `GetNavChain()` и `AddBufferContent()`. Поэтому его шаблон (`components/bitrix/breadcrumb/main/template.php`) **обязан вернуть строку** (`return $strReturn;`), а не печатать HTML. Если печатать — крошки уедут в начало страницы, а на их месте появится «1».

В остальных наших шаблонах (меню, форма, поиск) можно печатать как обычно.

### Имя шаблона у компонентов

В вызовах `IncludeComponent` вторым аргументом должно быть **имя папки** шаблона (`main`, `mobile`, `footer`), а не отображаемое имя из `.description.php`. Если через визуальный редактор вписать туда русское название (например «Хлебные крошки (main)»), Битрикс его отклонит и возьмёт дефолтный шаблон.

## Включаемые области

Текстовые и HTML-блоки вынесены в `include/` и редактируются штатно в админке (в режиме правки у области появляется кнопка редактирования). Логотип — `include/logo.php`, описание компании в подвале — `include/footer_description.php`, название — `include/site_name.php`.

## Расширения

Папки в `extensions/` — это заготовки под три типа сайтов. Битрикс о них ничего не знает, это просто ориентир для разработчика.

### Лендинг (`extensions/landing/`)
Герой-блок с CTA, блок преимуществ, этапы работы, отзывы, форма заявки.

### Новости (`extensions/news/`)
Лента новостей, детальная страница новости, список сотрудников, структура компании.

### Магазин (`extensions/shop/`)
Каталог с фильтрами, карточка товара, корзина, оформление заказа.

## Требования

- PHP 7.4+ (проверено на 7.4 и 8.1)
- В `php.ini` должен быть включён `short_open_tag = On` — шаблон использует короткие теги `<?`. На OpenServer он включён по умолчанию.

## Начало работы

1. Скопируйте папку `main` в `/local/templates/`
2. Примените шаблон: Администрирование → Настройки → Настройки продукта → Сайты → Шаблоны сайтов
3. Замените `assets/img/logo.svg` и `assets/img/favicon.svg` на свои
4. Поправьте цвета в `assets/css/styles.css`
5. Заполните включаемые области в `include/`
6. Скопируйте нужные страницы-образцы из корня шаблона в корень сайта
